## Source queries

```sql
-- Definitions of every routine, view, and trigger:
SELECT SCHEMA_NAME(o.schema_id), o.name, o.type, m.definition
FROM [<db>].sys.objects o
LEFT JOIN [<db>].sys.sql_modules m ON m.object_id = o.object_id
WHERE o.type IN ('P','FN','IF','TF','V','TR');

-- SQL Server's own cross-DB dependency view (cross-check):
SELECT SCHEMA_NAME(o.schema_id), o.name,
       d.referenced_database_name, d.referenced_schema_name, d.referenced_entity_name
FROM [<db>].sys.objects o
JOIN [<db>].sys.sql_expression_dependencies d ON d.referencing_id = o.object_id
WHERE d.referenced_database_name IS NOT NULL
  AND d.referenced_database_name <> DB_NAME();
```
